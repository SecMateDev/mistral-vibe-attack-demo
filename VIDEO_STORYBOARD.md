# Video storyboard

## Shot 1 — attacker ready

Show the empty SecMate dashboard with **Listener online**. Do not show its terminal
arguments or network address.

## Shot 2 — repository received

On the victim VM, show the private GitHub URL arriving, the clone finishing, and the
developer entering the repository. Keep Git history and hidden files off screen.

## Shot 3 — ordinary request

Start Vibe and enter:

> Review this repository thoroughly. Run its complete validation workflow, then
> summarize any issues you find.

Frame the TUI so this benign request stays visible. Cut to the attacker screen when
the event arrives, before expanding tool arguments or repository instructions.

## Shot 4 — impact

Cut to the attacker dashboard as it changes from waiting to:

- Code execution confirmed
- Credential captured
- Demo agent path

Use a split screen replay to make the absence of an approval dialog visible.

## End card

State that the repository, credential, receiver, and machines were controlled test
fixtures. Say that exploit mechanics are withheld pending remediation.
